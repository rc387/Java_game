# 2D Platformer Game

## About the Project
A 2D platformer developed in Java using the CityEngine physics library. The player navigates through levels, avoids enemies and hazards, and uses different abilities to progress through the game.

## Features
- **Player movement:** Keyboard-controlled movement and jumping.
- **Animations:** Character animations for running, jumping, attacking and other actions.
- **Enemies:** Enemies with health and collision interactions.
- **Combat:** Player attacks and defensive abilities.
- **Health system:** Player lives decrease when taking damage or hitting hazards.
- **Level timer:** A countdown timer adds a time limit to gameplay.
- **Multiple levels:** Different environments, platforms and challenges.
- **Audio:** Background music and sound effects.
- **Game UI:** On-screen statistics, including remaining time and player lives.

## Controls

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Ensure the required Java Development Kit and CityEngine library are configured.
4. Ensure the game assets are available in the expected `data` directory.
5. Run the main game class to start the game.

## Project Structure
- `GameWorld` – Creates the game world and manages its objects.
- `Character` – Handles player behaviour, movement, health and abilities.
- `Enemy` – Implements enemy behaviour and health.
- `Flag` – Represents a level objective.
- `GameWorldBackground` – Renders the background and on-screen information.
- `data/` – Contains images, animations and audio assets.
